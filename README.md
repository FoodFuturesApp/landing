# Food Futures

Workspace for building Food Futures: an app for everyday food choices that are better for you and the planet.

- `website/`: marketing site (rebuild of the Framer site). Run `cd website && python3 -m http.server 8000`.
- `docs/`: product context, design system, and dated notes in `docs/context/`.
- `data/`: raw data (gitignored).
- `tools/parity/`: checks the website against the live Framer site.

Start with `CLAUDE.md`.
